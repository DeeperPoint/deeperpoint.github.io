Contribute

Open to Anyone Who Wants In

DeeperPoint is a self-funded, pay-it-forward project with no investors and no board. The engine is MIT-licensed, nobody is locked in, and the work is done in the open. If you want to take part, this is where help lands.

The code

🧩
Code · MIT

Cosolvent

The matching engine, in its first usable beta: profiles, semantic matching, confidential disclosure, the Content Match Story and the Deal Brief. The contributor guide is in the repo.
📚
Knowledge · MIT

CommonContext

Turns reference documents, standards, contracts and trade guides into the domain schema and knowledge library a marketplace needs. Domain experts are as useful here as programmers.
🧫
Testing · Apache 2.0 with one condition

ClientSynth

Generates synthetic market populations so a marketplace can be exercised before real users arrive. Apache 2.0 with one condition: synthetic and real participants are never mixed.

Help that is not code

  • Knowledge of a market. A regulation, a standard, a certification route, the way deals really get done in a sector you know. That is what CommonContext is built to hold.
  • A market. If you work in a thin market and would let it be a test bed, say so.
  • Judgment. Read a catalog entry or a teardown and say where it is wrong. Candid assessment is worth more than encouragement.
  • Words. The cards, the catalog and the blog all take editing, and every page on this site can be improved.

How to start

  1. Read the fifteen cards for the short version of the thesis, or the whitepaper for the full one.
  2. Pick the repository and open an issue describing the problem, the expected behaviour and the scope, before writing code.
  3. Follow the contributor guide: one change set per pull request, tests and docs with it, the quality gate passing.
  4. For anything that is not code, or to ask before you start, write to the founder from the About page.

What this page asks for is work and judgment, not money. Cosolvent and CommonContext are free to adopt, fork and build on, and they stay that way: the only costs anyone carries are their own build and operations.
