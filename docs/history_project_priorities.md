> **Notable:** Entry #28 — the CoSolvent Video Gallery — is where the "CoSolvent" name originated. It was iPOV's YouTube-clone with structured video search, killed along with everything else when Flash died. Vic retained the domain name, and it was pragmatically reused for DeeperPoint's matching engine a decade later. The name connection is coincidental (domain reuse), not a deliberate brand lineage.
